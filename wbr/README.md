# WORLDWIDE BETTING RADAR – Chrome PWA

Standalone web app under `/wbr/`, independent of Floot/Base44 runtime. Supports JSON/CSV import, local persistence/export, worldwide fixture filtering, ID-mapped team-logo placeholders, source-aware live freshness, matchcenter stats/events, odds and strict forecast eligibility, and Brier/LogLoss on imported binary outcomes.

No fake live results, invented odds, or generated predictions. Browser version is a local-data client only; API secrets and automatic provider synchronization require a secure backend. Install from Android Chrome menu after HTTPS deployment.
